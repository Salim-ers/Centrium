# Si tu as identifié une vulnérabilité dans Centrium :
#
# 1. Envoie un email détaillé à security@centrium-platform.com
# 2. Décris la vulnérabilité, les étapes pour la reproduire, l'impact estimé
# 3. Inclue ta preuve de concept (vidéo, captures, requêtes)
# 4. Ne divulgue PAS publiquement avant qu'on ait confirmé un correctif
#
# Notre engagement :
#   - Accusé de réception sous 48h ouvrées
#   - Évaluation et triage sous 7 jours
#   - Correctif déployé selon la criticité (24h-90j)
#   - Reconnaissance publique (si tu le souhaites) dans notre Hall of Fame
#   - Bug bounty : programme en cours de lancement (Q4 2026)
#
# Hors-scope :
#   - Attaques nécessitant un accès physique à nos serveurs
#   - Ingénierie sociale contre nos employés
#   - Spam / déni de service (DDoS)
#   - Vulnérabilités sur des sous-traitants tiers (Supabase, Vercel...)
#     → reporte directement chez eux
