# Guide consultant — Portail Centrium

> Vous êtes consultant rattaché à une ESN cliente de Centrium. Voici
> comment utiliser votre portail dédié.

## Accès

Votre ESN vous a envoyé une invitation par email.

1. Cliquer sur le lien d'activation
2. Choisir votre mot de passe
3. Vous arrivez automatiquement sur **`/portal/dashboard`**

## Votre portail

L'espace consultant est séparé de l'espace ESN — vous ne voyez que vos
propres données.

| Section | Ce que vous y faites |
|---|---|
| `/portal/dashboard` | Vue d'ensemble missions + alertes |
| `/portal/cra` | Saisir et soumettre vos CRA mensuels |
| `/portal/contracts` | Consulter vos contrats |
| `/portal/invoices` | Vos factures (si freelance) |
| `/portal/documents` | Documents partagés par l'ESN |

## Compte rendu d'activité (CRA)

1. Aller sur `/portal/cra` chaque fin de mois
2. Cliquer sur le mois en cours → grille calendaire
3. Marquer chaque jour : **Travaillé / Congés / Férié / Maladie**
4. Ajouter un commentaire optionnel
5. Cliquer sur **« Soumettre »** quand c'est complet

Votre BM est notifié et valide. Si refusé, vous recevez un email avec
le motif et vous pouvez réouvrir / corriger.

## Vos données

`/portal/dashboard` → en bas, accès à :

- **Exporter mes données** : fichier JSON conforme RGPD
- **Demander la suppression** : envoie une demande à l'ESN

## Sécurité

- Mot de passe : 12 caractères minimum recommandés
- À la fermeture du navigateur, vous êtes automatiquement déconnecté
- Vous pouvez toujours vous reconnecter via le lien `/login`
