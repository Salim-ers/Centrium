# Guide utilisateur ESN

> Pour les **business managers**, **recruteurs** et **équipes finance**
> au quotidien.

## Vue d'ensemble

Centrium est organisé en 4 grands espaces :

1. **Pilotage** : `/dashboard` — KPIs temps réel
2. **Talent** : `/consultants`, `/matching`, `/cv-optimizer`
3. **Commercial** : `/crm`, `/contacts`, `/offers`, `/responses`
4. **Administratif** : `/missions`, `/contracts`, `/timesheets`, `/cra`, `/invoices`

## Parcours type — Répondre à un appel d'offres

1. **Recevoir l'offre** → l'enregistrer dans `/offers`
2. **Matching** → `/matching` cherche les meilleurs profils (score IA)
3. **CV Optimizer** → générer un CV brandé pour chaque profil retenu
4. **Réponse** → centraliser dans `/responses`
5. **Suivi pipeline** → `/crm` opportunité créée automatiquement

## Parcours type — Gérer un consultant en mission

1. **Créer mission** → `/missions/new`
2. **Affecter consultant** → fiche mission
3. **Générer contrat** → `/contracts` (template auto-rempli)
4. **CRA mensuel** → `/cra` ou portail consultant
5. **Validation** → BM valide les jours
6. **Facture client** → `/invoices` génère automatiquement

## Astuces clavier

| Raccourci | Action |
|---|---|
| `cmd/ctrl + k` | Recherche globale |
| `g` puis `d` | Aller dashboard |
| `g` puis `c` | Aller consultants |
| `g` puis `m` | Aller missions |

## Personnalisation

- **Thème** : clair / sombre via le menu utilisateur
- **Préférences cookies** : footer → « Gérer les cookies »
- **Mon profil** : `/settings/profile`
- **Mes données RGPD** : `/settings/privacy`
